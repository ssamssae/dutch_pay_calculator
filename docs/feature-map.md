## 구매 복원 결과 (T-260928-014)
- 진입: 설정 → 구매 복원. 처리 중에는 구매 내역 확인 중으로 표시하고 중복 탭을 무시한다.
- 실제 광고 제거 상품의 restored 이벤트가 확인된 경우에만 성공을 표시한다. 빈 구매 목록은 내역 없음, 스토어 연결 불가·오류·결과 미수신은 각각 안내한다.
- 기존 저장된 광고 제거 권한과 구매 스트림의 권한 적용은 유지한다. 로컬 저장 여부를 이번 복원의 성공 근거로 사용하지 않는다.
- 검증: test/purchase_restore_test.dart의 빈 이력·실제 복원·다른 상품·연결 불가·요청/스트림 오류·지연/미수신 경로. 실계정 StoreKit 복원은 실기기 미연결로 미확인.

## 사다리 탭 (T-261013-015)
- 진입: 앱 실행 → 하단 「사다리」 탭(계산기 · 사다리 · 설정).
- 기대: 참가자 이름(2~12명)과 결과 줄(라벨 × 개수)을 적고 「사다리 타기」를 누르면 사다리 화면으로 간다. 이름을 누르면 그 사람 경로를 그리고, 모두 보기·다시 섞기·결과 복사·처음으로를 쓸 수 있다. 마지막 입력은 기기에 저장돼 다음 실행 때 그대로 뜬다.
- 변경: 사다리요(ssamssae/sadariyo @ e184bdf)의 로직·화면 이식 — lib/ladder/, lib/screens/ladder_screen.dart·ladder_setup_screen.dart·ladder_tab.dart, MainShell 3탭. 저장 키 ladder_last_setup_v1. 시작 버튼 위 하단 배너 1개(광고 제거 구매 시 숨김). 사다리요의 앱 정보 시트는 옮기지 않음.
- 검증: flutter analyze 0건, flutter test 50개 통과(사다리 로직·설정·한 판·저장소 24, 사다리 흐름 1, 하단 탭 2, 기존 23). 실기기 실행은 아직 미확인(빌드 단계에서 확인).
